# NovaCoder Portfolio 🪐

Добро пожаловать в персональное интерактивное портфолио **NovaCoder**! Этот проект является единой витриной для трех наших ключевых разработок:
1. **NovaCode Studio** — Легковесный текстовый редактор с интеграцией Monaco Editor.
2. **NovaBeat Studio** — Веб-синтезатор барабанных сэмплов и степ-секвенсор.
3. **NovaAmbient Studio** — Эмбиент-плеер с режимом оверлея на рабочий стол.

Портфолио выполнено в футуристичном стеклянном стиле (Glassmorphism) с интерактивным Canvas-фоном, живыми Web Audio API демо-виджетами проектов и SSH-терминалом обратной связи.

---

## ✨ Особенности и Интерактивность

- **🌌 Интерактивный фон**: Canvas-анимация созвездий, притягивающихся к курсору мыши.
- **🥁 Интерактивный NovaBeat**: Позволяет создавать и воспроизводить биты Kick/HiHat прямо внутри карточки проекта в реальном времени. Звуки синтезируются процедурно через Web Audio API.
- **🍃 Интерактивный NovaAmbient**: Синтезирует процедурный шум дождя, костра (с треском углей) и ветра (с модуляцией частоты LFO).
- **✉️ SSH-Терминал (Обратная связь)**: Стилизованная консоль связи. Поддерживает мгновенную отправку сообщений в Telegram разработчику без настройки бэкэнда.

---

## 🚀 Как запустить локально

Поскольку проект использует Web Audio API и асинхронные HTTP-запросы (fetch), для корректной работы некоторых функций браузера рекомендуется запускать его через локальный сервер:

### Вариант 1: С помощью Python (встроенный модуль)
Если у вас установлен Python, выполните команду в папке проекта:
```bash
python -m http.server 8000
```
После этого откройте в браузере: `http://localhost:8000`

### Вариант 2: С помощью Node.js (npx)
Если у вас установлен Node.js, выполните:
```bash
npx serve
```

## ✉️ Настройка Telegram Bot API для обратной связи

По умолчанию терминал обратной связи работает в демонстрационном (симуляционном) режиме, логируя шаги шифрования и отправки в консоль. 

Чтобы сообщения с формы приходили напрямую к вам в Telegram:
1. Нажмите кнопку **`🔧 Configure Custom Telegram Bot API`** в нижней части терминала.
2. Введите токен вашего бота (`TG_BOT_TOKEN`) и ваш ID чата (`TG_CHAT_ID`).
3. Теперь при нажатии **`TRANSMIT MESSAGE`** форма сделает прямой запрос к API Telegram и доставит сообщение в ваш чат!

*Эти настройки сохраняются локально в сессии и не передаются на сторонние сервера, обеспечивая максимальную конфиденциальность.*

## 📦 Деплой на GitHub Pages

Проект готов к публикации на GitHub Pages.
1. Создайте публичный репозиторий `novacoder-portfolio` на GitHub.
2. Выполните пуш кода в репозиторий:
   ```bash
   git remote add origin https://github.com/NovaCoder/novacoder-portfolio.git
   git branch -M main
   git add .
   git commit -m "feat: initial release of portfolio showcase"
   git push -u origin main
   ```
3. Перейдите в настройки репозитория (**Settings -> Pages**) и выберите ветку `main` в качестве источника.
4. Ваш сайт будет доступен по адресу `https://novacoder.github.io/novacoder-portfolio/`.
